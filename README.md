# OOP Project — Database Manager

A Python Tkinter database management system created for a Year 11 Software Engineering project. 
## NOTE: this does not auto save so save

## Features
- Insert records
- Edit records
- Delete records
- Query by ID, name, age
- Sort records
- Save/load JSON database
- Clean Tkinter GUI

## Requirements
- Python 3.10+
- Tkinter (included with Python on Windows/macOS)
- Works on Windows, macOS, Linux

## How to Run
1. Download the project from this GitHub repository.
2. Open a terminal in the project folder.
3. Run: python gui.py

## Project Structure
- gui.py              # GUI
- classes.py          # Backend classes
- test_database.json  # Database file
- backup/             # Automatic backups
